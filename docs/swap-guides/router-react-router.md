# Swap: routing — TanStack Router → React Router 7

## Why swap

Your team is more familiar with React Router's API and conventions, or you want to use Remix-style loader/action patterns available in React Router 7's framework mode. Tradeoff: TanStack Router's type-safe route tree and built-in devtools are more ergonomic for large SPAs.

## What changes

| Aspect | Default (TanStack Router) | After swap (React Router 7) |
|---|---|---|
| Route definition | `createFileRoute` / `createRootRoute` | `routes.ts` or file-based (`routes/`) |
| Type safety | Auto-generated route tree | React Router's type inference |
| Data loading | `loader` functions in route files | `loader` (same concept, different API) |
| Devtools | TanStack Router Devtools | React Router devtools (limited) |

## Steps (high level)

1. Remove `@tanstack/react-router` and `@tanstack/router-vite-plugin`; add `react-router`
2. Replace `src/routeTree.gen.ts` pattern with React Router's `createBrowserRouter` or file-based routing
3. Convert `createFileRoute` route files to React Router `Route` components
4. Update `src/main.tsx` to use `RouterProvider` from `react-router`
5. Update Vite config: remove TanStack Router plugin

## Files touched

- `apps/web/package.json` — swap deps
- `apps/web/vite.config.ts` — remove TanStack Router plugin
- `apps/web/src/main.tsx` — swap router provider
- `apps/web/src/routes/` — convert route files to React Router format
- `apps/web/src/routeTree.gen.ts` — remove (generated by TanStack)
